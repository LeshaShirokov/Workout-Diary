# Дневник тренировок

Красивый дневник тренировок на чистом HTML, CSS и JavaScript вместо таблицы Excel. Без фреймворков, без сборки, без внешних библиотек и CDN. Работает офлайн, все данные хранятся только в вашем браузере.

**Открыть:** https://leshashirokov.github.io/Workout-Diary/

## Возможности

- **Сегодня** — выбор дня программы (подсвечивается следующий по очереди), старт тренировки, продолжение незавершённой, краткая статистика.
- **Тренировка**
  - крупные кнопки −/+ (шаг веса настраивается, по умолчанию 2,5 кг) и ввод с клавиатуры;
  - подсказки «было в прошлый раз» и кнопка «Как в прошлый раз» — заполняет пустые подходы весами и повторами прошлой тренировки этого дня;
  - таймер отдыха 30–180 с (запускается после отметки подхода, ±15 с, вибрация/звук по желанию);
  - кардио (минуты, км, ккал), вес тела, самочувствие и заметки;
  - черновик сохраняется автоматически — можно закрыть вкладку и продолжить;
  - итоги: объём (Σ вес × повторы, только для подходов с весом > 0), число подходов, длительность и личные рекорды с кубком.
- **Журнал** — календарь с отметками по дням программы, серия недель подряд, список тренировок, просмотр, редактирование, копирование и удаление.
- **Неделя** — таблица как в Excel: упражнения × подходы (вес / кол-во), дата и вес тела по каждому дню, объём, быстрый ввод кардио.
- **Прогресс** — собственные SVG-графики: максимальный вес, расчётный 1ПМ (формула Эпли), объём по упражнению, объём по неделям, частота тренировок, вес тела.
- **Программа** — редактор дней и упражнений: добавление, переименование, порядок, число подходов, тип (силовое / собственный вес / гравитрон / кардио), заметки.
- **Настройки** — тема (авто / светлая / тёмная), таймер, шаг кнопок, экспорт и импорт, демо-данные, очистка.
- Мобильная вёрстка в первую очередь, на компьютере — боковое меню и широкие таблицы. Светлая и тёмная темы.
- Устанавливается как приложение (PWA), работает без интернета, не даёт экрану погаснуть во время тренировки — см. раздел [Приложение (PWA)](#приложение-pwa).

## Как пользоваться

1. Откройте страницу. Программа (3 дня с упражнениями из таблицы) уже загружена.
2. Выберите день, нажмите «Начать», отмечайте подходы галочкой. Для гравитрона и других упражнений с противовесом вес вводится как помощь (отрицательное значение) и в объём не идёт.
3. Нажмите «Завершить» — тренировка попадёт в журнал, неделю и графики.

Хотите сначала посмотреть, как всё выглядит? «Загрузить демо-данные» на главном экране добавит историю с **вымышленными** числами. Удалить её можно в настройках.

## Перенос данных из Excel

Свои прошлые тренировки удобнее всего перенести JSON-файлом:

1. **Настройки → Импорт JSON → выбрать файл.**
2. Приложение проверит файл и покажет, что в нём: сколько тренировок, дней программы, записей веса.
3. Выберите **«Объединить»** (добавить к текущим данным) или **«Заменить всё»**. При необходимости включите «Сдвинуть даты».
4. Нажмите **«Импортировать»**.

Файлы с личными данными (`*-my-data*.json`) добавлены в `.gitignore` и в репозиторий не попадают.

## Экспорт

- **JSON** — полная резервная копия, её можно импортировать обратно на другом устройстве.
- **CSV** — для Excel: разделитель `;`, кодировка UTF-8 с BOM. Ячейки, начинающиеся с `=`, `+`, `-`, `@`, экранируются, чтобы Excel не принял их за формулы.

## Данные и формат

Данные хранятся в `localStorage` браузера:

| Ключ | Что хранится |
|---|---|
| `workout-diary:data` | всё состояние (схема версии 2): программа, тренировки, вес тела, настройки |
| `workout-diary:v1` | старый формат, автоматически переносится в v2 при первом запуске |
| `workout-diary:theme` | выбранная тема (чтобы страница не мигала при загрузке) |
| `workout-diary:data:corrupt-<время>` | резервная копия, если сохранённые данные оказались повреждены |

Файл экспорта:

```json
{
  "app": "workout-diary",
  "format": "workout-diary-export",
  "version": 2,
  "exportedAt": "2026-01-01T10:00:00.000Z",
  "data": {
    "program": { "days": [{ "id": "d1", "name": "День 1", "title": "…",
      "exercises": [{ "id": "d1-e1", "name": "…", "type": "strength", "sets": 3 }] }] },
    "sessions": [{ "id": "…", "date": "2026-01-05", "dayId": "d1", "dayName": "День 1", "status": "done",
      "bodyWeight": 70, "feeling": 4, "notes": "",
      "exercises": [{ "exId": "d1-e1", "name": "…", "type": "strength", "note": "",
        "sets": [{ "w": 20, "r": 12, "done": true }] }] }],
    "bodyLog": [{ "id": "…", "date": "2026-01-05", "weight": 70, "note": "" }],
    "settings": { "theme": "auto", "restSeconds": 90, "weightStep": 2.5 }
  }
}
```

Типы упражнений: `strength` (силовое), `bodyweight` (собственный вес, `w` — дополнительный вес), `assisted` (гравитрон: `w` — помощь, хранится отрицательным числом), `cardio` (минуты, км, ккал).

Импорт строго проверяет файл: размер не больше 5 МБ, ограничения на число и длину элементов, допустимые типы и диапазоны. Неизвестные поля и `__proto__` отбрасываются. Весь текст выводится через `textContent`, `innerHTML` не используется.

## Приложение (PWA)

Дневник — полноценное веб-приложение: ставится на главный экран, открывается в отдельном окне без адресной строки и работает без интернета.

### Установка

- **Android (Chrome, Edge, Samsung Internet):** откройте https://leshashirokov.github.io/Workout-Diary/ → кнопка «Установить приложение» в «Настройки → Приложение» (или подсказка на главном экране, или меню ⋮ → «Установить приложение» / «Добавить на главный экран»). Долгое нажатие на иконку открывает ярлыки «Начать тренировку», «Журнал», «Прогресс».
- **iPhone / iPad (Safari):** кнопка «Поделиться» → «На экран «Домой»» → «Добавить». Подсказка с этими шагами показывается только в Safari на iOS, пока приложение не установлено.
- **Компьютер (Chrome, Edge):** значок установки в адресной строке или кнопка в «Настройки → Приложение». Ярлыки доступны в контекстном меню иконки.

Если дневник уже открыт как приложение, подсказки и кнопки установки скрываются. Подсказку на главном экране можно закрыть крестиком — выбор запоминается.

### Офлайн

При первом открытии service worker (`sw.js`) сохраняет всю оболочку приложения: HTML, CSS, все скрипты, иконки и манифест. Дальше приложение открывается из кэша мгновенно и без сети — работают все разделы, можно провести и завершить тренировку. Когда сети нет, в шапке появляется значок «Офлайн».

- Файлы оболочки отдаются из кэша (cache-first), прочие файлы сайта — stale-while-revalidate.
- Любая навигация внутри приложения без сети получает сохранённый `index.html`.
- **Ваши тренировки в кэш не попадают** — они хранятся в `localStorage` этого браузера и никуда не отправляются.
- На `localhost` service worker можно отключить параметром `?nosw` (для разработки). При открытии `index.html` с диска (`file://`) приложение работает, но без офлайн-кэша.

### Обновления

Новая версия скачивается в фоне (проверка при каждом открытии, при возвращении на вкладку и раз в час; вручную — «Настройки → Приложение → Проверить обновления»), но **не включается сама**: внизу появляется уведомление «Доступна новая версия» с кнопкой «Обновить». По нажатию черновик тренировки сохраняется, новая версия активируется и страница перезагружается. Так обновление никогда не прервёт тренировку на середине. Старые кэши удаляются автоматически.

**Как поднимается версия кэша.** Список файлов и версия в `sw.js` генерируются скриптом:

```bash
node tools/build-sw.js          # пересобрать блок // <build:assets> в sw.js
node tools/build-sw.js --check  # проверить, что sw.js актуален (то же проверяет тест)
```

Версия — первые 10 символов SHA-256 от путей и содержимого всех файлов оболочки, поэтому меняется автоматически при любой правке. Добавили файл или изменили код — запустите `node tools/build-sw.js` перед коммитом; если забыть, упадёт `node --test`.

### Экран во время тренировки (Wake Lock)

На экране тренировки есть переключатель «Не гасить экран во время тренировки» (и такой же в «Настройки → Таймер отдыха и ввод», по умолчанию включён). Пока открыта незавершённая тренировка, экран не гаснет; при сворачивании браузер снимает блокировку, при возвращении приложение берёт её снова. Если браузер не поддерживает Screen Wake Lock API, переключатель не показывается.

### Надёжность хранения

Браузер может удалить данные сайта при нехватке места. В «Настройки → Приложение» есть кнопка «Защитить от очистки» (`navigator.storage.persist()`) — Chrome обычно разрешает это установленным приложениям, Firefox спрашивает пользователя. Там же видно, сколько места занимает дневник. Экспорт JSON всё равно остаётся лучшей резервной копией.

### Ограничения iOS

- Установка только через Safari вручную («Поделиться → На экран «Домой»») — кнопки «Установить» на iOS не бывает.
- У установленного приложения на iOS **своё отдельное хранилище**: данные, внесённые в Safari, в приложении не видны (и наоборот) — перенесите их экспортом/импортом JSON.
- Если приложением долго не пользоваться (около 7 дней без открытия во вкладке Safari), iOS может очистить данные сайта; у установленного на главный экран приложения этот риск ниже, но регулярный экспорт обязателен.
- Ярлыки иконки (shortcuts) и `persist()` на iOS не поддерживаются; Wake Lock — с iOS 16.4 (в установленном приложении — с iOS 18.4).

### Иконки и скриншоты

PNG-иконки (192/512 обычные и maskable, apple-touch-icon 180, favicon 32, иконки ярлыков) генерируются локально из SVG-логотипа: `node tools/make-icons.js`. Скриншоты для окна установки (`screenshots/`) снимаются на вымышленных демо-данных: `node tools/make-screenshots.js`. Обоим скриптам нужен Chrome и `puppeteer-core`.

## Запуск локально

Сборка не нужна. Service worker работает только по http(s), поэтому лучше открывать через любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
```

## Тесты

Юнит-тесты на встроенном тест-раннере Node.js (18+), без зависимостей:

```bash
node --test tests/*.test.js
```

Проверка PWA в Chrome (установимость, офлайн с остановленным сервером, полная тренировка без сети, обновление версии, Wake Lock, подсказки установки) — `NODE_PATH=<puppeteer-core> node tools/pwa-e2e.js` (локально) или `… node tools/pwa-e2e.js https://leshashirokov.github.io/Workout-Diary/`.

Покрыты: расчёт объёма и рекордов, 1ПМ, даты и недели, серии, разбор кардио, миграция v1 → v2 и повреждённые данные, импорт (вредоносные и слишком большие файлы, объединение и замена), защита CSV от формул, актуальность sw.js и состав предзагрузки, манифест (размеры и типы иконок, ярлыки, скриншоты).

## Ограничения

- Данные живут в одном браузере. Чтобы перенести их на другое устройство, сделайте экспорт и импорт JSON. При очистке данных сайта они пропадут — периодически делайте резервную копию.
- Ограничения iOS для установленного приложения — в разделе [Приложение (PWA)](#ограничения-ios).
- Формат даты в поле выбора даты зависит от языка браузера.
- Синхронизации между устройствами и аккаунтов нет — это осознанно: никакой сервер не видит ваши тренировки.

## Конфиденциальность

В репозитории только шаблон программы (названия дней и упражнений) и вымышленные демо-данные. Никакой аналитики, трекеров и внешних запросов.
