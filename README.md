# Дневник тренировок

Красивый дневник тренировок на чистом HTML, CSS и JavaScript вместо таблицы Excel. Без фреймворков, без сборки, без внешних библиотек и CDN. Работает офлайн, все данные хранятся только в вашем браузере.

**Открыть:** https://leshashirokov.github.io/Workout-Diary/

## Возможности

- **Сегодня** — выбор дня программы (подсвечивается следующий по очереди), старт тренировки, продолжение незавершённой, краткая статистика.
- **Тренировка**
  - крупные кнопки −/+ (шаг веса настраивается, по умолчанию 2,5 кг) и ввод с клавиатуры;
  - подсказки «было в прошлый раз» и кнопка «Как в прошлый раз» — заполняет пустые подходы весами и повторами прошлой тренировки этого дня;
  - таймер отдыха 30–180 с (запускается после отметки подхода, ±15 с, вибрация/звук по желанию);
  - кардио (минуты, км, ккал), вес тела, самочувствие и заметки;
  - черновик сохраняется автоматически — можно закрыть вкладку и продолжить;
  - итоги: объём (Σ вес × повторы, только для подходов с весом > 0), число подходов, длительность и личные рекорды с кубком.
- **Журнал** — календарь с отметками по дням программы, серия недель подряд, список тренировок, просмотр, редактирование, копирование и удаление.
- **Неделя** — таблица как в Excel: упражнения × подходы (вес / кол-во), дата и вес тела по каждому дню, объём, быстрый ввод кардио.
- **Прогресс** — собственные SVG-графики: максимальный вес, расчётный 1ПМ (формула Эпли), объём по упражнению, объём по неделям, частота тренировок, вес тела.
- **Программа** — редактор дней и упражнений: добавление, переименование, порядок, число подходов, тип (силовое / собственный вес / гравитрон / кардио), заметки.
- **Настройки** — тема (авто / светлая / тёмная), таймер, шаг кнопок, экспорт и импорт, демо-данные, очистка.
- Мобильная вёрстка в первую очередь, на компьютере — боковое меню и широкие таблицы. Светлая и тёмная темы.
- Устанавливается как приложение (PWA) и работает без интернета.

## Как пользоваться

1. Откройте страницу. Программа (3 дня с упражнениями из таблицы) уже загружена.
2. Выберите день, нажмите «Начать», отмечайте подходы галочкой. Для гравитрона и других упражнений с противовесом вес вводится как помощь (отрицательное значение) и в объём не идёт.
3. Нажмите «Завершить» — тренировка попадёт в журнал, неделю и графики.

Хотите сначала посмотреть, как всё выглядит? «Загрузить демо-данные» на главном экране добавит историю с **вымышленными** числами. Удалить её можно в настройках.

## Перенос данных из Excel

Свои прошлые тренировки удобнее всего перенести JSON-файлом:

1. **Настройки → Импорт JSON → выбрать файл.**
2. Приложение проверит файл и покажет, что в нём: сколько тренировок, дней программы, записей веса.
3. Выберите **«Объединить»** (добавить к текущим данным) или **«Заменить всё»**. При необходимости включите «Сдвинуть даты».
4. Нажмите **«Импортировать»**.

Файлы с личными данными (`*-my-data*.json`) добавлены в `.gitignore` и в репозиторий не попадают.

## Экспорт

- **JSON** — полная резервная копия, её можно импортировать обратно на другом устройстве.
- **CSV** — для Excel: разделитель `;`, кодировка UTF-8 с BOM. Ячейки, начинающиеся с `=`, `+`, `-`, `@`, экранируются, чтобы Excel не принял их за формулы.

## Данные и формат

Данные хранятся в `localStorage` браузера:

| Ключ | Что хранится |
|---|---|
| `workout-diary:data` | всё состояние (схема версии 2): программа, тренировки, вес тела, настройки |
| `workout-diary:v1` | старый формат, автоматически переносится в v2 при первом запуске |
| `workout-diary:theme` | выбранная тема (чтобы страница не мигала при загрузке) |
| `workout-diary:data:corrupt-<время>` | резервная копия, если сохранённые данные оказались повреждены |

Файл экспорта:

```json
{
  "app": "workout-diary",
  "format": "workout-diary-export",
  "version": 2,
  "exportedAt": "2026-01-01T10:00:00.000Z",
  "data": {
    "program": { "days": [{ "id": "d1", "name": "День 1", "title": "…",
      "exercises": [{ "id": "d1-e1", "name": "…", "type": "strength", "sets": 3 }] }] },
    "sessions": [{ "id": "…", "date": "2026-01-05", "dayId": "d1", "dayName": "День 1", "status": "done",
      "bodyWeight": 70, "feeling": 4, "notes": "",
      "exercises": [{ "exId": "d1-e1", "name": "…", "type": "strength", "note": "",
        "sets": [{ "w": 20, "r": 12, "done": true }] }] }],
    "bodyLog": [{ "id": "…", "date": "2026-01-05", "weight": 70, "note": "" }],
    "settings": { "theme": "auto", "restSeconds": 90, "weightStep": 2.5 }
  }
}
```

Типы упражнений: `strength` (силовое), `bodyweight` (собственный вес, `w` — дополнительный вес), `assisted` (гравитрон: `w` — помощь, хранится отрицательным числом), `cardio` (минуты, км, ккал).

Импорт строго проверяет файл: размер не больше 5 МБ, ограничения на число и длину элементов, допустимые типы и диапазоны. Неизвестные поля и `__proto__` отбрасываются. Весь текст выводится через `textContent`, `innerHTML` не используется.

## Запуск локально

Сборка не нужна. Service worker работает только по http(s), поэтому лучше открывать через любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
```

## Тесты

Юнит-тесты на встроенном тест-раннере Node.js (18+), без зависимостей:

```bash
node --test tests/*.test.js
```

Покрыты: расчёт объёма и рекордов, 1ПМ, даты и недели, серии, разбор кардио, миграция v1 → v2 и повреждённые данные, импорт (вредоносные и слишком большие файлы, объединение и замена), защита CSV от формул.

## Ограничения

- Данные живут в одном браузере. Чтобы перенести их на другое устройство, сделайте экспорт и импорт JSON. При очистке данных сайта они пропадут — периодически делайте резервную копию.
- Формат даты в поле выбора даты зависит от языка браузера.
- Синхронизации между устройствами и аккаунтов нет — это осознанно: никакой сервер не видит ваши тренировки.

## Конфиденциальность

В репозитории только шаблон программы (названия дней и упражнений) и вымышленные демо-данные. Никакой аналитики, трекеров и внешних запросов.
